# Neema Jelagat Kimutai: Portfolio

My personal portfolio website, built with **React** and **Vite**.

Live site: https://neeema-svg.github.io

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## Edit the content

All text, projects, skills and links are in [`src/data.js`](src/data.js).
Add an entry to a list and it appears on the site automatically.

## Deploy

Every push to `main` builds the site and publishes it to GitHub Pages
automatically (see `.github/workflows/deploy.yml`).
